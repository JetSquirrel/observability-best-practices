# 日志

# 日志输出到 `stdout`

在可能的情况下,应用程序应该输出日志到 `stdout`,而不是输出到固定位置如文件或套接字。这样可以让日志代理根据适合您的可观测性解决方案的规则来收集和路由日志事件。虽然并非所有应用程序都可以这样做,但这是容器化工作负载的最佳实践。

:::note
	虽然应用程序在日志记录实践中应该保持通用和简单,与日志解决方案保持松耦合,但日志数据的传输仍然需要[日志收集器](../tools/logs/)将数据从 `stdout` 发送到文件。重要的概念是避免应用程序和业务逻辑依赖于您的日志基础设施 - 换句话说,您应该努力实现关注点分离。
:::

:::info
	将应用程序与日志管理解耦可以让您在不更改代码的情况下调整和改进解决方案,从而最小化对环境进行更改时的潜在[影响范围](../faq/#what-is-a-blast-radius)。
:::
