# AWS 可观测性成熟度模型

## 引言

可观测性的核心是通过分析系统的外部输出来理解和洞察其内部状态。这一概念已经从传统的监控方法（侧重于预定义的指标或事件）演变为一种更全面的方法，涵盖环境中各个组件生成的数据的收集、分析和可视化。一个系统只有在被观察的情况下才能被控制或优化。有效的可观测性策略使团队能够快速识别和解决问题，优化资源使用，并深入了解系统的整体健康状况。可观测性提供了高效检测、调查和修复问题的能力，从而改善整体操作可用性和工作负载的健康状况。

![为什么需要可观测性](../images/Why_is_Observability_Important.png)

监控和可观测性之间的区别在于，监控告诉您系统是否在运行，而可观测性则告诉您系统为什么没有运行。监控通常是一种被动措施，而可观测性的目标是能够以主动的方式改进您的关键绩效指标（KPI）。持续的监控和可观测性提高了敏捷性，改善了客户体验，并降低了云环境中的风险。

## 可观测性成熟度模型

可观测性成熟度模型为希望优化其工作负载可观测性和管理流程的组织提供了一个基本框架。该模型为企业提供了一个全面的路线图，帮助它们评估当前的能力，识别改进的领域，并战略性地投资于正确的工具和流程，以实现最佳的可观测性。在云计算、微服务、短暂和分布式系统的时代，可观测性已成为确保数字服务可靠性和性能的关键因素。通过提供改进可观测性的结构化方法，该模型使组织能够更深入地理解和控制其系统，从而为更具弹性、高效和高性能的业务铺平道路。

## 可观测性成熟度模型的阶段

随着组织扩展其工作负载，可观测性成熟度模型也应随之成熟。然而，可观测性成熟度的路径并不总是与工作负载同步增长。其目的是帮助客户在扩展和增长其组织能力时达到所需的成熟度水平。

1. **第一阶段：基础监控 - 收集遥测数据**  
   作为最低要求，基础监控通常是孤立的，没有明确的策略来监控组织中的全部系统或工作负载。大多数情况下，不同的团队（如应用程序所有者、网络运营中心（NOC）、CloudOps 或 DevOps 团队）使用不同的工具来满足其监控需求，因此这种方法在跨团队调试或环境优化方面价值有限。  
   在此阶段，客户通常使用不同的解决方案来监控其工作负载。不同的团队通常以不同的方式收集相同的数据，因为与其他团队的合作有限或没有合作。团队倾向于根据他们获得的数据来优化他们的需求。此外，团队无法使用其他团队的数据，因为从其他团队获得的数据可能是不同格式的。制定计划以识别关键工作负载，争取统一的可观测性解决方案，定义指标和日志是此阶段的关键方面。

2. **第二阶段：中级监控 - 遥测分析和洞察**  
   在此阶段，客户看到他们的组织在从各种环境（如本地和云）收集信号方面变得更加清晰。他们设计了从工作负载中收集指标、日志和跟踪的机制，这些构成了可观测性的基础结构，创建了可视化、警报策略，并能够根据明确定义的标准优先处理问题。客户不再是被动的猜测，而是有一个工作流程来调用所需的操作，相关团队能够根据捕获的信息和历史知识进行分析和故障排除。

3. **第三阶段：高级可观测性 - 关联和异常检测**  
   在此阶段，组织能够清楚地了解问题的根本原因，而无需花费大量时间进行故障排除。当问题出现时，警报会为相关团队（如网络运营中心（NOC）、CloudOps 或 DevOps 团队）提供足够的上下文信息。监控团队能够通过关联指标、日志和跟踪等信号立即确定问题的根本原因。

4. **第四阶段：主动可观测性 - 自动和主动的根本原因识别**  
   在此阶段，可观测性数据不仅在问题发生后使用，而是在问题发生前实时使用。通过使用训练有素的模型，问题识别是主动进行的，解决方案也更容易和简单。通过分析收集到的信号，监控系统能够自动提供问题的洞察，并列出解决问题的选项。

## AWS Well-Architected 和云采用框架

组织可以利用 [AWS Well-Architected](https://aws.amazon.com/architecture/well-architected/) 和 [云采用框架](https://docs.aws.amazon.com/whitepapers/latest/aws-caf-operations-perspective/observability.html) 来增强其可观测性能力，并有效监控和排查其云环境。

## 评估

可观测性成熟度模型评估可用于衡量您当前的可观测性状态并识别改进的领域。每个阶段的评估涉及评估不同团队的现有监控和管理实践，识别差距和改进领域，并确定进入下一阶段的整体准备情况。

## 构建可观测性策略

一旦组织确定了其可观测性阶段，他们应该开始构建策略以优化当前流程和工具，并开始朝着成熟度迈进。组织希望确保其客户拥有良好的客户体验，因此他们从这些客户需求开始，并从中倒退。然后与利益相关者合作，因为他们非常了解这些需求。

## 结论

可观测性成熟度模型为组织提供了一个路线图，帮助它们评估当前状态并寻求改进其理解、分析和响应工作负载和基础设施行为的能力。通过遵循结构化方法来评估当前能力，采用先进的监控技术，并利用数据驱动的洞察，企业可以实现更高水平的可观测性，并对其工作负载和基础设施做出更明智的决策。
